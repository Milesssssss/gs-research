# E3 GS→Mesh 可仿真

占位。尚无 run，无模板，无结论。

本线记录从高斯基表示提取网格，并检查该网格能否进入仿真：尺度是否对齐、表面是否可用作碰撞体、导入物理引擎后是否立刻失效。表示可以是 3DGS 或 2DGS，步骤里必须写明。

整条 real-to-sim 冒烟（DISCOVERSE / MuJoCo / GraspClutter6D 的 C1、N1、P1）归 [E5](../E5-real-to-sim/README.md)。E3 不代替 E5 填写那三道门禁；E5 也不代替 E3 给出网格质量结论。

新增 run 时按 [docs/process.md](../../docs/process.md) 书写，文件放在 `runs/YYYY-MM-DD-<短名>.md`。
