# E2 质量—速度帕累托

占位。尚无 run，无模板，无结论。

本线记录渲染质量与代价的取舍，对象包括 3DGS 与 2DGS。质量侧常见量是 PSNR、SSIM、LPIPS；代价侧常见量是训练时间、渲染 FPS、峰值显存。具体定义以每次 run 所写的指标表为准。

只在本线宣布「质量—速度」结论。语义数字归 [E1](../E1-semantic-3dgs/README.md) 或 [E4](../E4-online-semantic/README.md)，网格能否仿真归 [E3](../E3-gs-to-mesh/README.md)。

新增 run 时按 [docs/process.md](../../docs/process.md) 书写，文件放在 `runs/YYYY-MM-DD-<短名>.md`。本目录以后会补 `runs/_template.md`，在那之前字段与 E1 模板对齐。
